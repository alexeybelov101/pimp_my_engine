# pimp_my_engine
**Русский** | [English](README.en.md)

Симулятор рабочих процессов в двигателе внутреннего сгорания.

## Статус проекта
Проект находится в ранней стадии разработки. Интерфейсы и структура могут изменяться без предварительного уведомления.

## Требования
Для сборки требуются:
- компилятор GCC с поддержкой стандарта C++26;
- библиотека nlohmann/json (заголовочная, устанавливается отдельно).

## Сборка
Проект использует Makefile. Доступны следующие цели:
- make или make release — сборка оптимизированной версии
- make debug — сборка отладочной версии
- make run — сборка и запуск
- make debug run - сборка и запуск отладочной версии
- make clean — удаление артефактов сборки

Пример:
```bash
make release
./bin/release/pimp_my_engine --config configs/config.json
```

## Использование
Запуск симуляции с параметрами по умолчанию:
```bash
./bin/release/pimp_my_engine
```

### Доступные опции командной строки:
    -t, --time TIME — время симуляции в секундах.
    -f, --freq FREQ — частота симуляции в герцах.
    -r, --rpm RPM — начальные обороты двигателя.
    -c, --config PATH — путь к файлу конфигурации.
    -h, --help — справка.

## Конфигурация
Параметры двигателя и впускной/выпускной систем задаются в JSON-файле (по умолчанию configs/config.json).
Все размеры указываются в миллиметрах, масса - в граммах, углы - в градусах.
Размеры деталей стандартного конфига взяты из открытых источников для двигателя 21011 и могут не соответствовать реальным.
